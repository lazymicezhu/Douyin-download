- 20 个查询接口的路径、HTTP 方法、参数及必填字段与官方 OpenAPI 对照；20/20 公开定价元数据返回对应路径。未逐个进行付费业务查询。

- 独立代码审查后修复旧临时素材累积、已回收缓存文件的恢复，以及相册事务提交阶段仍允许点击取消的问题。这些收尾更改随最终设备构建检查，未运行额外电脑测试。

安装包不包含 API Key；配置单独交付为 TikHub.txt / TikHub.env。密钥仅由 Keychain 读取并发送至 api.tikhub.io。

未使用用户签名证书，未在实体 iPhone 安装或验证系统相册中的实况播放。实体 iPhone 的文件导入、相册授权、各接口账户权限和实际数据返回情况由用户安装后验证。


## 2.1 更新（2026-10-10）

此版本未启动模拟器、未运行电脑测试，仅进行单任务设备构建和静态审查。

- 导入改用 UIKit 导入副本，协调文件提供方读取，保持安全访问；支持文本编码和粘贴整段 ENV。钥匙串写入后读回验证，签名权限错误显示实际错误码。实际导入与签名权限仍需真机验证。
- 新增本机费用历史及免费平台当日用量。已先核验 daily_usage 价格为零，再实读确认字段结构；没有调用收费业务接口。官方后台脚本将 balance_usage/free_credit_usage 显示为美元。参考 [费用接口记录](billing-history-api.md)。
- 静态审查修复了更换密钥期间旧每日用量请求结束后缺少补刷的竞态；报价与推算费用分开，历史不包含密钥或请求参数。
- 曾观察到普通 30fps 正常、原画 120fps 在相册中段慢放。使用 Apple full-frame-rate-playback-intent UInt8(1) 标记制作相册副本，保留源帧率、尺寸、压缩样本和时间戳。官方支持自 iOS 18 起。没有额外付费解析该样例或在电脑转码测试，真机修复效果仍待安装验证。
